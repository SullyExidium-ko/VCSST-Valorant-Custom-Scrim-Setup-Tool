# VCSST — Valorant Custom Scrim Setup Tool

발로란트 내전을 위한 Windows 데스크톱 룰렛 앱입니다.

제작: **Machos[마카오스]**

## 기능

- 맵 선택·제외와 랜덤 추첨
- 역할군별 요원 선택과 추첨
- 무기 스킨 검색·필터와 추첨
- 애니메이션 및 프로그램 UI 크기 설정

## 배포 안내

이 저장소는 설치 파일과 업데이트 내용을 제공하는 **배포 전용 저장소**입니다. 프로그램 소스코드는 이 저장소에 포함하지 않습니다.

검증이 완료된 설치 파일은 [Releases](https://github.com/SullyExidium-ko/VCSST-Valorant-Custom-Scrim-Setup-Tool/releases)에서 제공합니다.

현재 설치형 2.6.0 업데이트 기능을 준비 중이며, 아직 정식 업데이트 릴리스는 게시하지 않았습니다. 코드 서명 인증서와 서명된 첫 릴리스가 준비될 때까지 앱 내부 자동 업데이트는 활성화되지 않습니다. 저장소가 만들어져 있다는 사실만으로 업데이트가 제공되는 것은 아닙니다.

포터블 자동 업데이트는 현재 지원하지 않습니다.

## 업데이트 배포 파일

정식 릴리스에는 서명된 설치 EXE, `latest.yml`, 해당 `.blockmap`, 버전별 변경 사항을 함께 제공합니다. 이전 정상 버전은 복구용으로 보존합니다.

## 안내

VCSST는 Riot Games의 공식 프로그램이 아닌 팬 제작 도구입니다. VALORANT 관련 이름과 게임 자산의 권리는 각 권리자에게 있습니다.
